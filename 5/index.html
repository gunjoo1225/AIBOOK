Speed Dial 크롬 확장 설치💻 노트북

🔴 반드시 구글 크롬 브라우저에서 설치해야 합니다!

크롬이 아닌 다른 브라우저(엣지, 삼성 인터넷 등)에서는 설치되지 않습니다.
크롬을 열고 아래 주소를 주소창에 붙여넣어 주세요.

⚡ Speed Dial 설치하기 (크롬 전용) →
설치 방법 따라하기
1
Speed Dial 설치 페이지에서 파란색 「Chrome에 추가」 버튼을 클릭합니다.
2
크롬 탭 오른쪽의 「 + 」 버튼을 클릭하면 아래와 같은 화면이 나타납니다.
3
화면 중앙의 흰색 「 + 」 버튼을 클릭합니다.
4
새 창이 뜨면 「Link to the page」에 URL 주소, 「Caption」에 이름을 입력한 후 「Add」를 클릭합니다.
5
바로가기가 등록됩니다. 「 + 」 버튼을 반복해 나머지 AI 툴들도 모두 추가하세요.
🌟 세팅이 가능하신 분은 위 필수 설치 프로그램의 모든 AI 툴 링크를 Speed Dial에 등록해 두시면 교육 중 훨씬 빠르게 활용할 수 있습니다!
문의사항이 있으시면 교육 담당자에게 연락해 주세요.
